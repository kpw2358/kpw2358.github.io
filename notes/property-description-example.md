# 숙소 특징 예시

서울역 초역세권
단독으로 사용하는 렌탈 스튜디오입니다.
초역세권 1,4호선,공항철도,경의중앙선,KTX
건물인근 편의점,빨래방,까페,롯데 렌터카

2층이고 엘리베이터는 없지만 1층 계단만 오르면 됩니다.

## 교통편

서울역 15번출구 3분 거리 입니다.
주변 버스도 많아서 교통편 최고입니다.

주변시설 :
- 2분 거리 : 편의점, 카페, 코인세탁소
- 3-4분 거리 : 다이소, 식당, 지하철역

가까운 곳에 산책하기 좋은 서울로와 서울역 롯데마트부터 다이소까지 인프라가 매우 좋습니다.

## 기타 유의사항

✅ 공간렌탈은 위생용품을 일체 지급하지 않습니다.(침구와 타올,세면도구 등)
필요하신 경우 자체적으로 동반하시거나 대여업체로 안내해드릴수있습니다.
예약이 확정되면 체크인 전일에 주소랑 비번 안내드려요
